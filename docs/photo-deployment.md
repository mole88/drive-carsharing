## Исправление отображения фотографий

Позже 11 октября активный release обновлён до `d364276`. В браузере воспроизведён
старый JavaScript из кэша, который выводил SVG вместо фотографий. HTML теперь
содержит версию CSS/JS по хешу содержимого, а статика требует проверки кэша.
Отдельно подтверждён отказ загрузки BMW из-за лимита конкурентных запросов
Uvicorn. CSS, JavaScript и фотографии теперь отдаёт Caddy напрямую из
`/srv/drive-carsharing/current/app/static`, а HTML/API проходят через FastAPI.
Настройка Caddy проверена перед reload; прежний файл сохранён в
`/etc/drive-carsharing/Caddyfile.before-static-cache-fix`.

После обычного обновления той же браузерной вкладки все четыре фотографии имеют
ненулевые naturalWidth/naturalHeight и видны в каталоге. Скриншот подтверждения:
`tmp/car-photos-fixed.png`. Пройдены три проверки страниц и кэша и 16 JS-тестов.
Данные базы не изменялись; Gemini сохранил прежние PID, время запуска и NRestarts.
